# Global Day of Coderetreat 2026

This repo serves as content root for this year's GDCR in Vienna: https://swkwien.github.io/gdcr2026

## Run

Static site, serve [index.html](index.html) directly.

Requires some form of webserver in order to load the referenced md-files. I.e. via IDE, or via python:

```shell
python3 -m http.server
```

Then open http://localhost:8000
